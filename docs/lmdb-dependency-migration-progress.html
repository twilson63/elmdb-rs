Behavior notes (intentional, reviewed)

  • heed enforces one open Env per canonicalized path. The registry keys on the raw path string, so two spellings of one directory (e.g. /tmp vs /private/tmp on macOS) now fail with {error, environment_error, …} instead of silently opening a second env — safer, and LMDB explicitly documents double-open as corruption-prone.
  • Bundled LMDB moves from ~0.9.14-era (2014) to current mdb.master — same 0.9 on-disk format (verified empirically), with a decade of upstream fixes.
